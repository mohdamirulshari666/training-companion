# Training Companion V2

Personal training + nutrition PWA.

## Current working features
- iPhone-friendly PWA
- Local meal logging and persistence
- Camera/photo input
- kcal and macro totals
- Daily calorie target
- Offline cache
- COROS snapshot embedded for the current prototype

Live COROS refresh and automatic AI meal recognition need secure server-side integrations and are intentionally not faked in this static build.
